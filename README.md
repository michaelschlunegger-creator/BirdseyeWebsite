# Birdseye Website Prototype

A customer-focused website prototype for Birdseye Asset Solutions, built around the IDEA journey: Inspect, Digitize, Engineer and Assess.

## Public prototype

[View the Birdseye website](https://michaelschlunegger-creator.github.io/BirdseyeWebsite/)

## Local development

```bash
npm ci
npm run dev
```

The website is automatically built and published to GitHub Pages whenever the `main` branch is updated.
